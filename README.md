Luman is a modern hotel booking web application designed to replicate a premium hospitality experience through performance-focused frontend engineering, friction-less booking flows, and automated owner notifications.

This project demonstrates real-world frontend architecture, not just UI screens.

🎯 Project Goals

Build a conversion-focused hotel booking flow

Deliver sub-second performance on low-end mobile devices

Reduce booking friction using predictive UX

Automate customer & owner email communication

Ensure SEO-ready structure for hospitality searches

🚀 Core Frontend Innovations
1️⃣ Predictive Booking Engine

Auto-advancing date selection to reduce user effort

Enforced date validation (no invalid stays)

Compact booking summary instead of long forms

2️⃣ Mobile-First Interaction Design

Designed around thumb-reach zones

Minimal modal usage to avoid cognitive overload

Optimized for low-end Android devices

3️⃣ Automated Email System

Customer booking confirmation email

Hotel owner receives full booking details instantly

Location & stay metadata included for operational clarity
